# Игровой движок «Бэнг!»

Чистая логика игры без React. Правила — по `bang-rules.pdf` (версия 1.1); в комментариях указаны страницы.

```
gameReducer(состояние, действие) → новое состояние
```

Интерфейс только отправляет действия (`GameAction`) и читает состояние (`GameState`).
Что можно сделать прямо сейчас, интерфейс спрашивает у `rules/playability.ts` — той же функции, которой движок проверяет действия.

## Как устроена партия

- **`phase`** — этап хода: `TURN_START` (проверки) → `DRAW` (набор) → `PLAY` (розыгрыш) → `DISCARD` (сброс) → следующий игрок.
- **`prompt`** — чего игра ждёт от конкретного игрока (`actorId`): ответить на «Бэнг!», выбрать карту из «Магазина», спастись «Отдыхом»…
- **`queue`** — запросы, ожидающие очереди: цели «Гатлинга» и «Индейцев», покупатели «Магазина», проверки начала хода.
  После каждого действия `settle` (engine.ts) открывает следующий запрос, пропуская выбывших.

## Решения там, где правила допускают толкование

- Ангельские Глазки требуют двух «Мимо!» только против своих карт «Бэнг!» — «Гатлинг» картой «Бэнг!» не считается.
- «Отдых» в свой ход нельзя сыграть при полном здоровье — он бы ничего не дал.
- Запрос «спастись от гибели» открывается, только если «Отдыха» (и пар карт у Тома Кетчума) хватает, чтобы выжить.
